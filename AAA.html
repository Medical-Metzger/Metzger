Aortic Aneurysm Alert: An educational simulation.

This project was a successful collaboration between collgues Laura Hudson and Dunja Rashkova. This application was designed to make learning about aortic aneurysms more visual and engaging. It allows users to explore a series of themed rooms with 3D anatomical models, animations, videos, interactive activities and a final quiz.

Throughout this project I found creative ways of reusing the same base format for the design of each room to reproduce different user experiences utilizing 2d and 3d animations and graphics. I particularly enjoyed this blood spawner function, creating a script that continuously instantiates red-blood cells to produce a deluge effect. This recreated the imagery of internal bleeding in a visually lighthearted manner. Although this wasn’t a necessary feature for the objectives of this project as an educational application, personally think the BloodSpawner is an engaging and entertaining aspect of the application.
